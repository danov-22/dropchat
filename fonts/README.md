# Bundled fonts

BDO Grotesk Regular and Medium are from LCTipografi/BDO-Grotesk (Fonts/Webfont): https://github.com/LCTipografi/BDO-Grotesk

Roboto Mono Regular is from googlefonts/RobotoMono (fonts/webfonts): https://github.com/googlefonts/RobotoMono

Both are distributed under the SIL Open Font License. The unmodified license files are included alongside these fonts and copied into the production assets. Fonts are served locally; no Google Fonts or Webflow CDN request is required by DropChat.

The visual styling is independently written CSS inspired by the Noura reference: https://noura-template-supply.webflow.io/. No template JavaScript, imagery or Webflow runtime is used.
